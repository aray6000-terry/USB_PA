🚀 Google Sheet 模式二 (Apps Script 免伺服器) 快速部署指南

本系統採用 模式二 (Google Apps Script Web App) 輕量直連架構，免伺服器維護成本，並在前端透過 Web Crypto API (AES-256 / SHA-256) 實施資料加密防護。


三分鐘部署步驟：

  1. 在您的 Google Drive 建立一個新的 Google 試算表 (Google Sheet)。
  2. 在試算表選單點選 「擴充功能」 > 「Apps Script」。
  3. 將專案根目錄下的 googleAppsScript_Code.gs 內容全部複製並貼入編輯器中，點選儲存。
  4. 點選右上角 「部署」 > 「新的部署作業」。
  5. 類型選擇 「網頁應用程式 (Web App)」，設定：
    • 執行身分：我 (您的 Google 帳號)
    • 誰可以存取：所有人 (Anyone)
  6. 完成部署後，複製產生的 Web App 網址。
  7. 點擊本系統右上角 ⚙️ 設定按鈕，將網址貼上並儲存，系統即可立即雙向即時同步！

🔒 前端資料庫加密說明： 傳輸時敏感商務報價、付出佔比與審核請求皆附帶雜湊防偽簽章與加密密鑰，防止中途竄改或竊聽。
