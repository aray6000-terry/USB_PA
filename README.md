# 優德美科技 · 軟體工程師績效考核與專案積分管理系統

本系統為優德美科技打造之標準化績效考核平台，直連 Google Sheet 資料庫（模式二：免伺服器輕量 Web App），並具備前端資料庫傳輸安全加密（AES-256 / SHA-256）、四級角色權限 (RBAC)、主管多工程師付出佔比設定、助理專案與每月上傳審核，以及各工程師分佈圖與去年同期 (YoY) 比較分析。

---

## 核心特色與考核規則

### 1. 考核對象與計分歸屬
- **只評估「軟體工程師」**：專案工程師（硬體）欄位保留供工程協同檢視，不計入績效積分。
- **認列時點**：專案以 **「軟體完成時間」** 作為計分年度與月份之歸屬基準；若尚未結案則顯示為進行中。

### 2. 專案基準分計算公式
1. **智慧建築 (Smart Building)**:
   $$\text{專案基準分} = \left(\frac{\text{報價金額}}{10000}\right) \times \text{等級係數}$$
   - 合格：$\times 1.0$
   - 銅級：$\times 1.05$
   - 銀級：$\times 1.10$
   - 黃金級：$\times 1.15$
   - 鑽石級：$\times 1.20$
2. **非智慧建築 (依戶數級距)**:
   - $\le 20$ 戶：**4.0 分**
   - $21 \sim 50$ 戶：**5.0 分**
   - $51 \sim 100$ 戶：**6.0 分**
   - $101 \sim 200$ 戶：**8.0 分**
   - $201$ 戶以上：**10.0 分**
3. **維護專案**:
   - 固定 **1 案 1 分**（整合項目包含「維護」或標註為維護專案時優先套用）。
4. **每月固定上傳資料**:
   - 每月固定上傳且助理審核通過：**0.2 分 / 月**。

### 3. 多工程師付出佔比 (主管填寫)
- 若專案有多位軟體工程師（例：`林軟體, 李程式`），由主管於介面上點擊 **「✏️ 調整佔比」** 填寫每位工程師的付出佔比（例如 $60\% / 40\%$，總和須為 $100\%$）。
- **工程師實得積分** = $\text{專案基準分} \times \text{個人付出佔比}$。

### 4. 去年同期比較表 (YoY Comparison)
- 支援「年度 (例如 2026 vs 2025)」與「月份 (例如 2026-05 vs 2025-05)」即時對比。
- 圖表與明細表直觀呈現：本期積分、去年同期積分、增減差額、成長率 (%) 與專案量對比。

## 四級角色權限 (RBAC) 規範

| 角色 | 權限範圍 | 專屬功能 |
| :--- | :--- | :--- |
| **1. 超級使用者 (Admin)** | 全公司全域資料 | 可查看所有人員、新增/編輯專案、調整佔比、最高審核權 |
| **2. 主管 (Manager)** | 轄下管轄工程師資料 | **專屬功能：填寫與調整多位軟體工程師之付出佔比**、指派工程師、檢視團隊成員績效 |
| **3. 工程師 (Engineer)** | 僅可看個人負責專案 | 個人積分儀表板、個人專案清單、個人每月上傳紀錄與審核狀態 |
| **4. 助理 (Assistant)** | 專案進度與上傳紀錄 | **可新增專案**、**專屬審核「每月固定上傳資料 (0.2分)」**、**審核「專案完成比例 (%)」** |

## 快速啟動與本機預覽

系統已內建免安裝相容伺服器 `server.js`（相容於所有 Node.js 版本）：

```bash
# 啟動本機伺服器
npm start
# 或直接執行
node server.js
```

啟動後請於瀏覽器開啟：
👉 **http://localhost:3000**

> 本系統亦支援直接雙擊開啟 `index.html`，內建現代瀏覽器 LocalStorage 安全沙盒，可立即體驗所有功能！

## Google Sheet 串接步驟 (模式二：Apps Script 部署)

1. 開啟您的 **Google 雲端硬碟**，建立一個新的 **Google 試算表 (Google Sheet)**。
2. 點選頂部功能表之 **「擴充功能」 > 「Apps Script」**。
3. 清空原有代碼，將本專案目錄下的 `googleAppsScript_Code.gs` 全部內容複製貼上。
4. 點選右上角 **「部署」 > 「新的部署作業」**。
5. 齒輪圖示選擇 **「網頁應用程式 (Web App)」**：
   - 說明：`優德美績效考核 API`
   - 執行身分：`我 (您的 Google 帳號)`
   - 誰可以存取：`所有人 (Anyone)`
6. 點選 **「部署」** 並授權存取試算表。
7. 複製產生的 **網頁應用程式網址 (URL)**（例如：`https://script.google.com/macros/s/.../exec`）。
8. 返回本系統首頁，點擊右上角 **⚙️ 設定按鈕**，將網址貼入並點選儲存，試算表即自動初始化並開始同步！

## 前端資料庫傳輸安全加密機制

- 前端採用標準 **Web Crypto API (AES-256-GCM / SHA-256)**。
- 每次資料提交與同步請求皆通過安全簽章核對與金鑰檢驗，確保試算表資料在傳輸途中不會被篡改或竊聽。
- 預設金鑰為 `YouDeMei-Secure-Kpi-Key-2026`，您可在 `googleAppsScript_Code.gs` 與前端設定面板中自訂您的專屬金鑰。
